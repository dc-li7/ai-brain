# Topics

_The topic list for this memory scope. memory-index reads it to build the tree in `index/`. One line per topic, starting with a dash: `- slug: what's inside`, for example `- work: Clients, projects and the tools I use for them`. A sub-topic uses a slash (`work/clients`). Slugs are lowercase letters, digits and dashes, at most 3 levels deep. A memory picks its topic with `topic: <slug>` under `metadata:` in its frontmatter; without one it lands in Unsorted. Edit this file by hand. Keep each summary short and concrete: it's what lets an AI skip a whole branch without opening it._
